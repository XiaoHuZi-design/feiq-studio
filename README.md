# 飞秋工作室 (FeiQ Studio)

一个**单文件**的局域网协作 + 个人研发管理工作台：HTML 一个文件就是全部前端，配一个 Node 本地代理即可解锁群聊、文件互传、AI 助手等全部能力。

> 灵感来自经典局域网办公工具飞秋（FeiQ），用现代 Web 技术复刻并扩展。

## ✨ 功能

### 🤖 AI 助手（多厂商）
- **只贴 Key 就能用**：Key 自动识别厂商（`sk-cp-`→MiniMax、`sk-ant-`→Claude、`id.secret`→智谱…）、自动定协议、自动拉取账号下**全部可用模型**
- **Key 按厂商记忆**：每家设一次，切换厂商自动带出
- **发送框旁模型下拉**：所有已配置厂商的全部模型 ID 分组列出，点选即整套切换
- **自动 CORS 路由**：实测各厂商跨域能力，MiniMax/DeepSeek/Kimi/Qwen 等直连；智谱/GPT/Claude/Gemini/百炼自动走本地代理
- 智能配置失败时给出**可操作的提示**（如"需启动本地代理"），不让用户怀疑 Key 填错
- 快捷指令（生成晨会稿/优先级建议等）点击直接发送；支持多配置保存切换

### 💬 局域网群聊（复刻 FeiQ）
- 基于 WebSocket + UDP 信标的**真实多机互通**：自动发现同网段节点、互加好友
- 文件/图片互传（代理中转存储）、@提及、表情、IP 直发、画板
- 空间（部门/项目/研发）与动态博客

### 📋 研发管理
- 每日计划（任务/标签/工时、任意日期回看补记）、晨会稿自动汇总
- 月度 OKR → 周 KR → 每日执行的可拆解链路，样机进度 EVT/DVT/PVT/量产阶段流转
- 历史回顾热力图、月度复盘导出 Markdown
- 分析笔记

### 🎨 皮肤引擎
- 主色/圆角/字号/密度/侧栏宽全可调，日夜模式，实时预览

## 🚀 快速开始

```bash
# 1. 启动（二选一）
#    a) 直接双击 index.html 用浏览器打开（单机功能全可用）
#    b) 启动本地代理，解锁群聊/AI 代理转发等全部能力
node feiq-proxy.js        # 或双击 启动代理.bat

# 2. 浏览器访问
http://127.0.0.1:8787/
```

局域网其他电脑访问 `http://<你的IP>:8787/` 即可互加好友聊天。

### AI 配置（以智谱为例）

1. 打开「AI → 接口设置」（⚙ 设置）
2. 点厂商列表里的 **Zhipu GLM**，贴入 API Key
3. 直接发消息 —— 协议/地址/模型列表全自动

无 CORS 的厂商（智谱/GPT/Claude/Gemini/百炼）需本地代理在跑（页面会明确提示）。
可用 `静默启动代理.vbs` 放入 Windows「启动」文件夹实现开机自启、后台运行。

## 📁 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 全部前端：工作台 + 飞秋复刻 + AI 助手（单文件） |
| `feiq-proxy.js` | Node 本地代理：静态托管 / 群聊 WS+UDP / 文件中转 / AI 转发 |
| `启动代理.bat` | Windows 一键启动代理 |
| `静默启动代理.vbs` | 静默启动（无窗口），适合放开机自启 |
| `使用说明.md` | 中文使用手册（功能/厂商实测表/常见坑） |
| `instrument-rd-workbench.html` | 早期独立版研发工作台（已并入主文件，留档） |

## 🛠 技术栈

纯原生 HTML/CSS/JS（零构建、零依赖框架）+ Node.js（仅标准库，`ws` 为可选增强）。
所有数据存 localStorage，Key 不上传任何第三方。
